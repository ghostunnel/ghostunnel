Security release. Identical to v1.11.4 except that it is built with Go 1.27.3
or later.

## Security

* **Go 1.27.3.** Builds now require Go 1.27.3, which adds a denylist to
  `crypto/x509` so that certificate chains through the compromised eMudhra
  intermediate CA keys fail verification (CVE-2026-111943, GO-2026-6809).
